# 05 - 用户操作指南（使用者视角）

> 适用对象：**实际用这个系统发内容的人**（运营 / 创作者），不是开发、也不是运维。
> 目标：照着做，就能从「什么都没有」到「一条内容成功发到小红书/抖音/快手」。
> 开发视角的代码结构见 [02-项目导览.md](./02-项目导览.md)；管理员/运维配置见 [../daily-usage.md](../daily-usage.md)。

> 本文所有界面路径都基于 **管理后台（Vue）**。地址：
> - 本地：`http://127.0.0.1:8765/app/`
> - 服务器：`http://<服务器IP>:8000/app/`（或负责人给你的域名）

---

## 一、先搞懂：系统里有两个「创作」入口

左边菜单有两个容易混的入口，先分清：

| 入口 | 菜单名 | 干什么 | 适合谁 |
|------|--------|--------|--------|
| **内容创作** | `内容创作` | 用 AI  brainstorming 出文案/图片/视频素材，**产出自用内容**，存草稿 | 先想内容、慢慢打磨的人 |
| **发布向导** | `发布` | 选平台 + 账号 + 内容 → **一步步引导你发到某个平台** | 要直接把东西发出去的人 |

**典型工作流**：
- 想先让 AI 帮你想点子、出文案图 → 进 **内容创作**，满意了存草稿。
- 准备好要发了 → 进 **发布**，把内容填进去，选平台账号，提交后执行。

两者都最终会落到「发布任务」，在 **发布任务** 页面统一管理和执行。

---

## 二、第一次登录

1. 浏览器打开管理后台地址，跳到登录页。
2. 用负责人给你的账号密码登录。

| 角色 | 账号（默认） | 密码（默认） | 能做什么 |
|------|------|------|------|
| 管理员 | `admin` | `admin123` | 全部，含系统设置、用户管理 |
| 运营 | `operator` | `operator123` | 创作、发布、平台账号 |
| 审核主管 | `reviewer` | `reviewer123` | 仅审核，不能发布 |
| 只读 | `viewer` | `viewer123` | 只能看 |

> ⚠️ 默认密码是公开的，**第一次登录后请改密码**（右上角头像 → 修改密码）。
> 登录后看到的是 **工作台**，上面有统计卡片和告警提示。

## 三、准备平台账号（发之前必须先做）

发内容前，你得先把**目标平台的账号**登录进系统（系统靠它自动登录去发）。

1. 左侧菜单 → **平台账号**。
2. 点 **新建账号**，选平台（小红书 / 抖音 / 快手），填账号备注名。
3. 点该账号的 **扫码登录** → 弹出二维码。
   - **本地开发**（你本机跑的）：用手机 App 扫真实二维码。
   - **服务器部署**：二维码会直接显示在弹窗里，用对应 App 扫（无需你本机 Chrome）。
4. 扫码后在 App 上确认登录。回到页面点 **校验 Cookie**，显示 `有效` 即成功。

> 账号需要分组管理？点 **分组管理** 建分组，把账号归到组里，发布时可以按组筛选。
> Cookie 会过期（平台风控），失效后校验会报 `无效`，重新扫码登录即可。

## 四、方式一：用「内容创作」先产出内容

左侧菜单 → **内容创作**。

步骤条：**灵感输入 → 文案创作 → 内容生成 → 生成状态**

1. **灵感输入**：选「视频内容 / 图文内容」，填主题/关键词，可选风格、品牌色等。
2. **文案创作**：点「生成文案」，AI 按平台调性出标题+正文+标签，可手动改。
3. **内容生成**：图文可「生成封面图」；视频可生成或上传。
4. **生成状态**：全部满意后，**保存到素材库** 或 **存草稿**。

> 草稿会出现在「草稿箱」，下次进来可「继续创作」或「查看成果」。

---

## 五、方式二：用「发布向导」直接发（最常用）

左侧菜单 → **发布**（发布向导）。这是把内容发出去的主路径。

步骤条：**主题账号 → AI 文案 → 内容生成（封面）→ 素材确认 → 排期提交**

### Step 1：主题账号
- **内容模板**（可选）：如果有预设模板，选一个快速填充。
- **发布平台**：小红书 / 抖音 / 快手（B站、视频号标「实验」的需管理员开启）。
- **内容类型**：图文 / 视频。
- **发布账号**：选第三步登录好的账号（没有就去「平台账号」先登录）。
- **主题**：这条内容讲什么。

### Step 2：AI 文案
- 点「生成」按平台模板出标题、正文、标签，可在框里直接编辑。
- 想换 AI 模型？去 **AI 模型** 页面看当前用的哪家（一般自动匹配，不用管）。

### Step 3：内容生成（封面）
- **图文**：点「AI 生成封面」出图，或上传本地图片；可选风格/比例/品牌色。
- **视频**：可选 3:4 视频封面（小红书支持），其他平台可跳过。

### Step 4：素材确认
- **图文**：选准备好的图片（刚才生成的或上传的）。
- **视频**：选/上传 MP4；小红书可附带封面图。

### Step 5：排期提交
- **计划时间**（可选）：填了就会到时间**自动发**；不填就要手动点执行。
- 两个按钮：
  - **保存草稿**：先存着不改。
  - **提交待发布**：进入发布任务队列，等执行（若开了内容审核，会先到「待审核」）。

---

## 六、执行发布（在「发布任务」页）

1. 左侧菜单 → **发布任务**。
2. 找到你刚提交的任务（状态 `待发布`）。
3. 点 **执行** → 系统用 Playwright 自动登录账号、填内容、发布。
4. 点 **查看日志** 看实时进度（哪一步成功/失败）。

状态含义：

| 状态 | 意思 | 你能做的 |
|------|------|----------|
| 草稿 | 还没提交 | 编辑 / 删除 |
| 待审核 | 开了审核，等审核主管通过 | 等 |
| 待发布 | 排队中，等执行 | 执行 |
| 发布中 | 正在自动发 | 看日志 |
| 成功 | 发完了 | 查看 |
| 失败 | 出错了 | 看日志改了重试 |
| 已驳回 | 审核没过 | 看原因，退回草稿改 |

> 设了计划时间的任务会**自动执行**（每 30 秒轮询一次到点任务），不用手动点。

---

## 七、如果开了「内容审核」（看情况）

负责人可能在系统设置开了审核。这时你「提交待发布」的任务会先到 **内容审核 → 待审核** Tab，审核主管通过后才进 `待发布` 队列。

- 被驳回会告诉你原因，改完重新提交即可。
- 你（运营）在 **发布任务** 页也能看到快捷「通过/驳回」按钮（审核主管角色才有审核权）。

---

## 八、素材库（管理你产出的内容）

左侧菜单 → **素材库**。

- 类型筛选：**图片 / 视频 / 文案**，可预览全文或缩略图。
- 发布向导里生成的图、上传的素材都会进这里，可复用。
- 不想要的可以删（注意：被发布任务引用的删不掉，先处理任务）。

## 九、常见卡点 & 怎么办

| 现象 | 大概率原因 | 怎么办 |
|------|------------|--------|
| 扫码后一直「无效」 | Cookie 过期 / 扫码没在 App 确认 | 重新扫码登录，App 里点确认；再点校验 |
| 点执行没反应 / 卡住 | 账号 Cookie 失效，或 Chrome 没起来 | 去平台账号重新扫码；看任务日志 `step=` 哪步卡 |
| AI 文案生成报错 | 没配 AI Key，或模型不可用 | 告诉负责人配 `DASHSCOPE_API_KEY` 等；或换模型 |
| 封面图是 1×1 小图 | 文生图 Key 没配 | 改用「上传图片」代替 AI 生成；或让负责人配 Key |
| 提交后状态一直是「待审核」 | 系统开了内容审核 | 正常，等审核主管通过；或催一下 |
| 任务被限频不执行 | 同账号发太频繁 / 超日上限 | 等一会儿，或让管理员调限频配置 |
| 标签「AI发布」被跳过 | 平台不认这标签，非阻塞 | 换常见标签如「日常」「分享」 |

> 更全的运维向问题见 [../daily-usage.md](../daily-usage.md) 第 8 节。

## 十、一句话流程回顾

```
登录 → 平台账号扫码登录 → 内容创作(可选，产出素材) / 发布向导(填内容) 
     → 提交待发布 → 发布任务页点执行 → 看日志等成功
```

第一次走完这条线，你就已经会用这个系统了。后面熟练了可以玩模板、排期自动发、素材复用。
